# Review queue, round 2: Review by day

A design branch for #17. It holds no app code and is not for merging.

- `index.html` is the clickable board. Download it and open it in a browser. It has phone and desktop views, light, dark and system themes, and desktop keys.
- `SPEC.md` is the full spec: row actions, the "needs a look" rule, the badge, the data and backend changes, and the milestones.
- `NOTES.md` is the designer's notes, including the dark theme's colour tokens and contrast ratios.
- `shots/` holds the screenshots, each in a light and a dark version.

Every name and figure is invented.
